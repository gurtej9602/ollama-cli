Ollama CLI features a full-screen, terminal-native user interface built on the [Charm](https://charm.sh) ecosystem using **Bubble Tea**, **Lipgloss**, and **Glamour**.

## Live Streaming

Tokens generated by your local Ollama model are rendered immediately as they are streamed via NDJSON:

- Zero perception lag — you see output the moment the first token arrives.
- Dynamic spinner indicator while the model prepares and starts inference.
- Smooth viewport auto-scrolling that keeps your active view centered on new text.

---

## Markdown Rendering

All AI responses are formatted and highlighted via [Glamour](https://github.com/charmbracelet/glamour):

- **Fenced Code Blocks**: Highlighted with syntax coloring according to language.
- **Tables & Lists**: Clean ASCII/Unicode table borders and bullet hierarchies.
- **Inline Formatting**: Bolding, italics, blockquotes, and links.

---

## Color Themes

Ollama CLI ships with multiple built-in color themes to fit your terminal aesthetics.

You can configure your theme in `~/.ollamacli.yaml`:

```yaml
theme: dracula # Options: dark, dracula, nord, monokai, ocean, forest, sunset
```

| Theme | Description |
| :--- | :--- |
| `dark` | Clean default dark palette with emerald accents |
| `dracula` | Popular purple/pink contrast theme |
| `nord` | Muted arctic blue and frost tones |
| `monokai` | Classic high-contrast vibrant coder theme |
| `ocean` | Deep sea blues and cyan highlights |
| `forest` | Calming earth greens and gold accents |
| `sunset` | Warm amber, coral, and violet tones |

## Keyboard Shortcuts

| Shortcut | Description |
| :--- | :--- |
| `Enter` | Submit your prompt |
| `Shift + Enter` | Insert a newline without sending |
| `↑` (Up Arrow) | Cycle to previous message from history |
| `↓` (Down Arrow) | Cycle forward in history |
| `Ctrl + L` | Scroll directly to the bottom of the chat viewport |
| `Ctrl + C` | Cancel active response stream; press again to exit |
