## Prerequisites

- **Go 1.22** or newer installed.
- Git.

Verify your Go installation:
```bash
go version
```

---

## Local Build

Clone the repository and compile the executable:

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    git clone https://github.com/gurtej9602/ollama-cli.git
    cd ollama-cli

    # Download dependencies
    go mod download

    # Compile with stripped debug symbols for small binary size
    go build -ldflags="-s -w" -o ollama-cli .

    # Run
    ./ollama-cli
    ```
  </Tab>

  <Tab title="Windows (PowerShell)">
    ```powershell
    git clone https://github.com/gurtej9602/ollama-cli.git
    cd ollama-cli

    # Download dependencies
    go mod download

    # Build binary
    go build -ldflags="-s -w" -o ollama-cli.exe .

    # Run
    .\ollama-cli.exe
    ```
  </Tab>
</Tabs>

## Cross-Compilation

Go's built-in toolchain makes cross-compiling for other operating systems and CPU architectures straightforward:

### Linux (x86_64)
```bash
GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o ollama-cli-linux-amd64 .
```

### macOS (Apple Silicon / M1 / M2 / M3 / M4)
```bash
GOOS=darwin GOARCH=arm64 go build -ldflags="-s -w" -o ollama-cli-darwin-arm64 .
```

### macOS (Intel)
```bash
GOOS=darwin GOARCH=amd64 go build -ldflags="-s -w" -o ollama-cli-darwin-amd64 .
```

### Windows (64-bit)
```bash
GOOS=windows GOARCH=amd64 go build -ldflags="-s -w" -o ollama-cli-windows-amd64.exe .
```
